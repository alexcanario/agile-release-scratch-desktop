## Install

- Install once with Scratch-win-Setup.exe: a copy unzipped from an earlier release does not update itself; from this release on, the app does.
- Windows SmartScreen warns because the installer is not signed: click "More info", then "Run anyway".
- Linux: download Scratch.AppImage, put it in ~/Applications, run `chmod +x` on it and start it from there. A copy unzipped from an earlier zip does not update itself; the AppImage does.
- Linux: the first update downloads the full package; the next ones download only what changed.
- Linux: AppImageLauncher (optional) adds the app to the menu.
